# F-002 · Zaufanie do treści karty

**ID:** `E-004/F-002` · **Status:** `parked` · **Epic:** [E-004](../../README.md).

**Problem / hipoteza:** błędna treść utrwala błędną wiedzę; sprawdzanie jakości i proste zgłoszenie mają chronić naukę.

**Zakres do discovery:** punkt 5 rozdziału 5 [analizy](../../sources/analiza-pedagogiczna-produktowa.md). Korekta karty już istnieje — najpierw ocenić lukę, nie budować jej od nowa i nie dublować zgłoszeń z E-001/F-007.

**Warunki gotowości / akceptacja:** ustalić próbkę jakości, rodzaje błędów i dopuszczalne progi; wykazać działającą ścieżkę zgłoszenia i bezpiecznego odzyskania poprawnej wersji. Brak przykładów nie może wpuszczać do ćwiczeń; podgląd glos nadal dozwolony.

**Zależności:** kontrakty E-002/F-004 i ścieżki zgłoszeń E-001/F-007; uzgodniona jakość przed historiami E-004/F-003.

**Poza zakresem:** blokowanie podglądu aż do pełnego `ready`, dodatkowe LLM do każdej karty bez mierzalnej potrzeby.

**Taski:** brak do zakończenia discovery. **Weryfikacja:** ocena próbki i regresja gotowości/zgłoszeń. **Dowody:** brak.
