# F-003 · Słowa ucznia w kontekście

**ID:** `E-004/F-003` · **Status:** `parked` · **Epic:** [E-004](../../README.md).

**Problem / hipoteza:** rozpoznanie izolowanego słowa nie daje jeszcze użycia w tekście. Krótka historia ze słów ucznia może uzupełnić, nie zastąpić, odtwarzanie z pamięci.

**Zakres do discovery:** punkt 6 rozdziału 5 [analizy](../../sources/analiza-pedagogiczna-produktowa.md). Dobór słów, kontrola słownika, powtórzenia haseł i pytania o słowa, nie samą fabułę. Model płatności i ilość generacji nie są zatwierdzone.

**Zależności:** E-004/F-001 (obciążenie), E-004/F-002 (jakość), kontrakty/koszt E-002; bez historii na nieopanowane zaległości.

**Warunki gotowości / akceptacja:** wybrać poziom/rozmiar/próbkę, próg pokrycia słownikiem i budżet AI; ocenić odroczone przypomnienie lub użycie wobec samej fiszki. Dowód, że tekst zachowuje zakres słów i nie dodaje niekontrolowanego obciążenia.

**Poza zakresem:** otwarty czat, voice/STT, wdrożenie subskrypcji. **Taski:** brak przed wyborem wariantu i progów. **Weryfikacja / dowody:** badanie i kontrola treści/kosztu do zaplanowania, brak wyników.
