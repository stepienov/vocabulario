# F-001 · Regularność bez przeciążenia

**ID:** `E-004/F-001` · **Status:** `parked` · **Epic:** [E-004](../../README.md).

**Problem / hipoteza:** po przerwie duża kolejka zniechęca. Porcje zaległości, zapowiedź obciążenia i krótkie wyjaśnienie odstępów mogą zwiększyć ukończenie powtórek.

**Zakres do discovery:** punkty 1–4 rozdziału 5 [analizy](../../sources/analiza-pedagogiczna-produktowa.md); najpierw sprawdzić, co już istnieje. Nie zmieniamy SRS ani nie dodajemy kar za przerwę bez decyzji.

**Warunki gotowości / akceptacja:** zmierzyć bazowy powrót po przerwie i ukończenie zaplanowanej porcji, zatwierdzić progi; scenariusz powrotu ma skończoną sesję, jasny pozostały zakres i ustalone zasady nowych kart. Nie manipulować metryką samym zmniejszeniem planu bez oceny efektu nauki.

**Zależności:** stabilna beta E-001, zachowanie danych i gotowości E-002. F-003 korzysta z rozwiązania przeciążenia, nie odwrotnie.

**Taski:** brak, potrzebne decyzje/progi i wybór wycinka. **Weryfikacja:** scenariusz użytkownika + pomiar odroczonego przypomnienia/regularności. **Dowody:** brak.
