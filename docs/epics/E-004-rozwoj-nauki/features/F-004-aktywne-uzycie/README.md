# F-004 · Aktywne użycie fraz, form i zdań

**ID:** `E-004/F-004` · **Status:** `parked` · **Epic:** [E-004](../../README.md).

**Problem / hipoteza:** odtworzenie lemma nie oznacza odtworzenia zwrotu lub formy w zdaniu. Wąskie ćwiczenie na danych istniejącej karty może uzupełnić lukę.

**Zakres do discovery:** punkty 7, 8 i 10 rozdziału 5 [analizy](../../sources/analiza-pedagogiczna-produktowa.md). Wybrać jeden wycinek: fraza, odmiana lub pisane zdanie; nie implementować trzech trybów naraz.

**Zależności:** E-004/F-002 i gotowość kart E-002/F-004. Brak przykładów nadal blokuje ćwiczenie; nie uzależniać całej dotychczasowej nauki od nowego trybu.

**Warunki gotowości / akceptacja:** ustalić języki, sposób oceny dopuszczalnych odpowiedzi, koszt oraz próg poprawy odroczonego użycia frazy/formy. Pomyłka oceniającego musi mieć zrozumiały feedback i drogę zgłoszenia.

**Poza zakresem:** mówienie, mikrofon i STT z historycznego punktu 11, dowolny czat, zmiana istniejącego SRS w ciemno.

**Taski:** brak przed wyborem wariantu. **Weryfikacja:** przykłady poprawnych/wariantowych/błędnych odpowiedzi i ocena użytkowa. **Dowody:** brak.
