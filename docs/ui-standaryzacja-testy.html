Testy standaryzacji UI

Odpal apkę (najlepiej UI po polsku). Idź po kolei. Przy każdym kroku zaznacz, czy wygląd się zgadza. Porównaj z makietami: ui-ux-porownanie.html. Blur tła wymaga Androida 12+ (API 31); poniżej ma być przynajmniej przyciemnienie.

Wzorzec Auth Onboarding Dodaj Listy Settings Nauka Korekta

Zaznaczone: 0 / 0

0. Wzorzec — sprawdzaj przy każdym oknie

To nie jest osobny ekran. Te 6 rzeczy mają być prawdą za każdym razem, gdy otworzy się dialog albo szuflada.

  1. Tło za oknem jest przyciemnione; na Androidzie 12+ też rozmyte.
  2. Karta dialogu na środku (~92% szerokości), rogi 24 dp, przyciski małe (nie 48 dp jak stary CardBlocking).
  3. Zatwierdzenie akcji = napis OK, kolor wypełnienia #569252 (nie jasna zieleń Easy ze starych buildów).
  4. Odrzucenie = Anuluj (nie Wróć / Wstecz). W dialogu decyzji Anuluj jest czerwone, outlined. W usuwaniu Anuluj jest bez koloru, a czerwone jest tylko Usuń / Przerwij.
  5. Pole do wpisywania = szary prostokąt, zaokrąglenie 24 dp, bez ramki dopóki nie klikniesz. Dropdown języka / CEFR zostaje pillem.
  6. W dialogu nie ma: Utwórz, Importuj, Zatwierdź N, Zastosuj, Zapisz, Dodaj jako confirm.
OK / Easy #569252 Edytuj / Historia #74AEAB Anuluj (decyzja) / Usuń

1. Auth — szare pola

Wyloguj (Settings → Wyloguj) albo świeża instalacja. Wyloguj nie ma modala potwierdzenia — to celowe.

  1. Ekran logowania: email i hasło.
    Szare prostokąty 24 dp, nie pill z ramką. Przycisk Zaloguj / Zarejestruj zostaje jak był (to nie dialog).

2. Onboarding — dropdown języka

Tylko nowe konto albo profil bez języków. CEFR na onboardingu nadal jest listą radio — tak miało zostać.

  1. Dropdown języka natywnego i języka nauki.
    Ten sam pill + surface co w Settings, nie goły OutlinedTextField.

3. Tab Dodaj — search, wiersz, głos, import, dodaj do listy

Home → tab dodaj.

  1. Puste wyszukiwanie (nic nie wpisane).
    Jedna linia podpowiedzi, padding ~40–56 dp, bez drugiej linii hintu.
  2. Pole szukaj.
    Szary prostokąt 24 dp (nie pill).
  3. Wpisz znane słowo (np. hiszpańskie, jeśli uczysz się ES). Kandydat na liście.
    Karta 18 dp, lemat + gloss, po prawej koło + 40 dp.
  4. Mikrofon → overlay głosu. Powiedz słowo albo zamknij X.
    Zostaje overlay (ciemny scrim + X), nie sheet. Tło przyciemnione + blur. Kandydaci: ta sama karta 18 dp i koło 40 dp.
  5. Na kandydacie naciśnij +. Sheet „Uczę się / Inna lista”.
    Szuflada z dołu; tło za nią przyciemnione/blur. To nie jest dialog OK/Anuluj.
  6. Inna lista → Nowa lista.
    Osobny dialog na środku (nie pole w szufladzie): szare pole nazwy, Anuluj czerwone + OK zielone. Szuflada może zostać pod spodem.
  7. W pickerze list (Inna lista, bez nowej): przycisk na dole.
    Napis Anuluj, nie Wróć.
  8. Import z pliku albo Wklej. Dialog startu importu.
    Chrome jak wzorzec. Confirm = OK (nie Importuj). Pole wklejki / nowa lista = szary 24 dp. Dropdown listy = szare pole z caretą (nie pill Settings).
  9. W starcie importu wybierz „Nowa lista” i wpisz nazwę.
    To samo szare pole; zatwierdzenie całego startu nadal OK.
  10. Odpal import i w trakcie naciśnij przerwanie (jeśli widać Anuluj/X na statusie).
    Dialog: tylko pytanie, bez opisu. Anuluj bez koloru + Przerwij czerwone.
  11. Po recenzji słów zatwierdź import.
    Confirm = OK, nie „Zatwierdź N”. Wynik: OK zielone; „Pokaż listę” zostaje jako drugi, nijaki przycisk.

4. Tab Listy — tworzenie, przenoszenie, usuwanie, filtr

Home → tab listy. Chip + tworzy listę.

  1. Pusta lista (albo lista bez słów).
    Sam tekst pustego stanu, padding ~40 dp, jedna linia, bez hintu pod spodem.
  2. Chip + → nowa lista. Wpisz nazwę, zatwierdź, potem Anuluj na innym teście.
    Dialog na środku, blur, szare pole, Anuluj czerwone + OK zielone. Nie „Utwórz”.
  3. Menu chipa zwykłej listy → Zmień nazwę.
    Ten sam modal co nowa lista (szare pole, Anuluj + OK).
  4. Menu listy → Usuń listę (albo na słowie ⋮ → Usuń).
    Tylko pytanie. Bez akapitu opisu. Anuluj bez koloru + Usuń czerwone.
  5. Lista „Uczę się” → Wyczyść wszystkie (jeśli są słowa).
    Jak wyżej: pytanie + Anuluj nijaki + Usuń (nie „Wyczyść”).
  6. Na słowie ⋮ → Przenieś. Albo multi-select → przenieś. Albo menu listy → przenieś wszystkie.
    Jeden układ: dropdown (szare pole 24 dp, lista po tapnięciu). Na dole trzy przyciski: Anuluj (czerwony) | Nowa lista (zielony outlined) | OK (zielony filled). „Nowa lista” nie jest linkiem pod polem.
  7. W pickerze Nowa lista → OK na nazwie.
    Wraca do dotychczasowego flow create-then-move (modal nazwy na środku, potem przeniesienie).
  8. Filtr (ikona filtra) → zmień coś → przycisk po prawej.
    Napis OK, nie Zastosuj. Szuflada: tło przyciemnione/blur.
  9. Sortowanie — otwórz i zamknij.
    Sheet, blur w tle. Wybór pozycji zamyka (bez pary Anuluj/OK — to lista opcji).
  10. Słowo needs_review (jeśli masz) → dialog „Czy chodziło Ci o”.
    Małe przyciski. Confirm = OK, nie Zatwierdź. Kafelki propozycji: karta 18 dp jak wiersz słowa.

5. Settings — CEFR, czasy, języki, limit

Ikona koła zębatego w nagłówku Home.

  1. Sekcja Poziom.
    Tylko tytuł „Poziom” — bez A1/A2 pod spodem, bez kreski, bez etykiety „Znajomość języka…”. Dropdown pill pokazuje aktualny poziom.
  2. Języki — dropdowny.
    Pill + surface, wypełnia szerokość.
  3. Układ karty / czasy: radio Wszystkie / Wybrane → Edytuj.
    Modal 92%, małe Anuluj + OK (nie Zatwierdź), blur.
  4. Limit nowych kart — pole liczby + przycisk.
    Szare pole 24 dp. Przycisk OK w zieleni #569252 (akordeon, nie modal).
  5. Godzina przypomnienia (powiadomienia).
    Szare pole 24 dp.

6. Nauka (Ucz się) — pusto, type, błąd, Easy, drzwi, zwroty

Przycisk Ucz się na dole Home. Potrzebujesz kart due albo pustej kolejki.

  1. Pusta kolejka (albo naucz wszystko i wejdź znowu).
    Tylko practice_empty — bez drugiej linii hintu. Przycisk wstecz to nawigacja (Powrót), nie dialog.
  2. Settings → tryb wpisywania, potem fiszka type.
    Pole odpowiedzi = szary 24 dp.
  3. Choice: kliknij złą odpowiedź.
    Dialog błędu na środku, blur, jeden przycisk OK zielony (nie Powrót).
  4. Rewers + oceny. Porównaj Easy z OK z innego dialogu.
    Easy jest w tej samej zieleni #569252 co OK (zmiana globalna).
  5. Rewers — rząd ocen.
    Tylko 4 przyciski SRS (Again / Hard / Good / Easy). Bez „Zgłoś poprawkę” i „Historia zmian” przy ocenach — korekta zostaje na liście (ikony).
  6. Słowa pokrewne na rewersie (+ jeśli jest).
    Ta sama karta 18 dp i koło 40 dp co na Dodaj, nie lista z kreskami.
  7. Zwroty / usages — tap, żeby otworzyć podgląd.
    Rogi 24 dp, tap w tło zamyka, brak Anuluj/OK. Blur.
  8. Historia zmian (teal button albo ikona na liście).
    Sheet, blur w tle. Tytuł sheetu może zostać „Historia karty” — to nie ten sam string co przycisk.

7. Korekta i self-edit

Z rewersu fiszki albo z kafelka na liście (ołówek / ⋮).

  1. Zgłoś poprawkę — sheet zgłoszenia.
    Blur za szufladą. Pole notatki = szary 24 dp. „Wyślij zgłoszenie” zostaje (to nie dialog OK).
  2. Wejście w edycję karty (self-edit). Pola + POS.
    Pola wpisywane szare 24 dp. POS = pill dropdown. Przycisk na dole = OK, nie Zapisz. Anuluj zostaje. Blur za sheetem.
  3. Zmień coś i zapisz tak, żeby API zwróciło ostrzeżenie (albo niepoprawne pole).
    Tytuł Potwierdzasz zmiany? + ikona ostrzeżenia. Opis czerwony. Anuluj czerwone + OK zielone, małe. Anuluj wycofuje, OK stosuje.
  4. Jeśli backend odrzuci zgłoszenie — dialog odrzucenia.
    Dwa przyciski, bez OK: Anuluj czerwone outlined + Edytuj (nie „Edytuj samodzielnie”) w #74AEAB. Nagłówek blisko opisu, nie jako osobna półka.
  5. Zaakceptowana korekta (jeśli trafi).
    Jedno małe zielone OK.
