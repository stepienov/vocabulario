How to install Vocabulario (Android)
====================================

This is a test build — you install it from an APK, not from Play Store.


1. Download the APK on your phone
   Open this Google Drive folder on your phone.
   Open Vocabulario.apk and tap Download.

   If you see a warning that the file may be harmful —
   that is normal. Choose “Download anyway”.


2. Allow installation
   Settings → Apps → Drive / Chrome / Files
   → Allow from this source → ON


3. Install
   Open the downloaded Vocabulario.apk (Downloads or the notification).
   Tap Install, then Open.


4. Create an account
   Sign up with email and password.
   Google sign-in may not work in this test build.


If installation is blocked — go back to step 2.
You need Android 8.0+ and an internet connection.

Thank you for testing.
